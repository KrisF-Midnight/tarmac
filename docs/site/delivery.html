Chapter 4

Delivery

CI never touches the cluster — it edits one line of YAML and pushes, and a reconciler inside the cluster pulls that commit and makes it true.

Moving parts

Argo CD reconciles, app-of-apps. Plain Kubernetes YAML — no Helm, no Kustomize, no overlays. The promoter is a Bun program in tarmac; Flux and Argo CD Image Updater were rejected.

Desired state

Desired state is what the cluster should run, held in git. Here that is gitops/ inside tarmac, not a separate deployment repository, and a reviewer owns every line but the image.

Sync & reconciliation

Reconciliation is a pull, not a push: Argo CD polls main every three minutes, so nothing outside needs a way in. make suspend stops it so hand edits stick.

Known gap

selfHeal reverts edits to resources Argo tracks, not one it never knew about: a hand-applied pod ran eight minutes with every Application reporting Synced.

Promotion

Promotion turns a published artefact into desired state. The promoter writes the digest into gitops/<app>/deployment.yaml and pushes, refuses anything not digest-pinned, and never writes from a laptop.

Blast radius

CI holds no cluster credential. What a merge may do is bounded by the tarmac AppProject, and Argo CD refuses any resource it does not list.

BoundWhat it allows
RepositoryOne. An Application cannot point at git nobody reviewed here
DestinationsNamespaces greeter and argocd, on the local cluster
Cluster-scopedNamespace only — so a merge cannot grant itself a ClusterRoleBinding
NamespacedFive kinds by name. EndpointSlice is absent on purpose, so a machine-specific address cannot be committed
CI’s tokenA GitHub App installation token, one repository, one hour. Nothing cluster-facing

Rollback

Rolling back is git revert down the path a promotion already takes; there is no second mechanism to keep working. Argo CD’s one-click rollback is refused while automated sync is on.

Where to look
  • tarmac/gitops/argocd/bootstrap/root.yaml — the only Application applied by hand; everything else is a file it discovers
  • tarmac/gitops/argocd/bootstrap/project.yaml — the allowlist every synced resource is validated against
  • tarmac/gitops/greeter/deployment.yaml — the deployed manifest, and the one line CI owns
  • tarmac/promote/src/manifest.ts — locate the container structurally, edit the line textually, re-parse to check it landed
  • tarmac/scripts/reconcile.sh — break glass, and why it stops the controller rather than one Application
