Chapter 7

Docs and omissions

Five documents a platform owes its readers — the entry point, the reasoning, the absences, the table that must not go stale, and the path to a first green run.

Moving parts

Four Markdown files in docs/ and a README — about 2,500 lines, of which decisions.md is 1,800. make gate-matrix generates one of them from gates/src/registry.ts; make check-gate-matrix diffs it in CI. No wiki, no site generator.

Entry point

The README is the document nobody is sent to and everyone reads. Twelve sections, prerequisites to breaking glass, each handing the reader off — to a first make up, or to the entry that says why.

Decisions

Fifty-eight numbered entries: why, what was rejected, what it costs. Nothing is rewritten — entry 45 corrects entry 39 by superseding it, and both stay readable.

Omissions

Absences sorted by honesty: cut before the work started, cut with it in reach, and gaps — missing with no defence, because dressing a hole up as a choice is what such a page invites.

Generated

One document is not written at all. make gate-matrix renders the gate table from the registry the runner reads; make check-gate-matrix diffs it. A stale matrix fails the platform’s own pipeline.

The limit of generating

The drift check compares the file to what the generator emits, not to what is true. The rows are pinned to the registry; the preamble above them is a string literal inside the generator, so a sentence that is wrong there regenerates cleanly forever — and reading the output can never reveal it.

Onboarding

Onboarding is one-time setup in order, ending with what to watch and in which order. It names the two steps that are clicks in a web UI, and why neither can be automated.

Where to look
  • tarmac/README.md — the way in, and the only document that assumes you have read none of the others
  • tarmac/docs/decisions.md — the fifty-eight entries, then every accepted cost gathered into one closing table and every rejected tool into a running list
  • tarmac/docs/omissions.md — each absence under a heading that says which kind it is, ending with the gaps that carry none
  • tarmac/docs/gate-matrix.md — generated by renderGateMatrix in gates/src/report.ts; its first line tells you to edit the registry instead
  • tarmac/docs/onboarding.md — the GitHub App, the two secrets, the manual visibility click, and the re-run that must produce no commit
